# Portfólio | Kaique Oliveira Batista

Portfólio pessoal desenvolvido para apresentar minha trajetória, habilidades e projetos na área de desenvolvimento Front-End.

## Sobre o projeto

O site apresenta uma interface responsiva e reúne:

- Apresentação profissional e download do currículo;
- Projetos desenvolvidos durante minha formação e estudos;
- Habilidades e tecnologias utilizadas;
- Informações sobre formação acadêmica e cursos complementares;
- Links de contato, GitHub e LinkedIn;
- Navegação adaptada para dispositivos móveis.

## Tecnologias

- Vue.js 3;
- TypeScript;
- Vite;
- HTML5;
- CSS3;
- Devicon para os ícones das tecnologias.

## Projetos apresentados

- [E-commerce](https://ecommerce-seven-iota-36.vercel.app/): loja virtual com produtos, categorias e carrinho de compras;
- [Catálogo de Filmes](https://movie-finder-five-xi.vercel.app/): aplicação com busca e informações de filmes usando a API TMDB;
- [Dashboard de Estoque](https://dashboard-amber-iota-22.vercel.app/): acompanhamento de produtos, estoque e categorias;
- [Sistema de Chamados](https://sistema-de-chamados-mu.vercel.app/): sistema CRUD para gerenciamento de chamados;
- [LanchesJá](https://lanches-ja.vercel.app/): catálogo de lanchonete com detalhes de produtos e carrinho;
- [Controle Financeiro](https://controle-financeiro-vert-one.vercel.app/): controle de receitas e despesas pessoais.

Os links para os repositórios do GitHub também estão disponíveis na seção de projetos do site.

## Como executar

### Pré-requisitos

- Node.js;
- npm.

### Instalação

```bash
npm install
```

### Desenvolvimento

```bash
npm run dev
```

### Build de produção

```bash
npm run build
```

### Prévia do build

```bash
npm run preview
```
